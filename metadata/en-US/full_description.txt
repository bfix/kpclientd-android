<b>IMPORTANT: This app requires a rooted device with the 'su' command available (for example via Magisk).</b>

Katzenpost is a mixnet implementation based on the Loopix design. The Loopix anonymity system was developed with financial support from the European Union's Horizon 2020 research and innovation program under Grant Agreement No. 653497, as part of the broader PANORAMIX (Privacy and Accountability in Networks via Optimized Randomized Mix-nets) project (see https://panoramix-project.eu/software/).

The <tt>KP Damon</tt> app starts and stops the <i>Katzenpost client daemon (kpclientd)</i> for Android. The client daemon is a local gateway to the Katzenpost mixnet (see https://github.com/katzenpost/katzenpost/cmd/client). It serves - depending on its configuration - an abstract Unix socket (<tt>@katzenpost</tt>), a file-based Unix socket or a TCP socket that can be used by multiple, concurrent clients (e.g. chat) to participate in the mixnet. The configuration for Android is based on abstract Unix sockets.

The Katzenpost daemon has a built-in configuration file but that can be out-dated at the time you want to run the daemon. Get a new configuration file (called <tt>client.toml</tt>) from the Katzenpost project and copy it into the <tt>/sdcard/Download/</tt> folder. If this file is present, it will be used instead of the built-in configuration.

The app screen will show the elapsed time for the current state (either "started" or "stopped") and (toggable) the last lines from the log output of kpclientd.

You can built your own custom mixnet clients to communicate with custom services running on the mixnet. For Android it is recommended to use the "thinclient" Go-bindings from the Katzenpost project, write the client logic for the mixnet protocol in Go and compile this code with <tt>gomobile</tt> into an AAR (Android Archive). Now Java (or Kotlin) can be used to write the GUI and to call the AAR for messaging.
